# 한빛아카데미 브랜드 프로토타입

한빛아카데미 메인페이지 리뉴얼을 위한 반응형 브랜드 웹사이트 프로토타입입니다.

## 방향

- Apple Higher Education의 여백과 실사 중심 화면
- Pearson의 사람 중심 교육 스토리텔링
- MIT Press의 기술 출판사 정체성
- 도서 목록 없이 브랜드 소개와 주요 서비스 연결에 집중

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 주요 메뉴 연결

- 책: https://www.hanbit.co.kr/academy/books/new_book_list.html
- 교수전용공간: https://www.hanbit.co.kr/academy/professor/index.html
- 정보교과서: https://www.hanbit.co.kr/textbook/
- 교재 단체구매: https://www.hanbit.co.kr/grouporder/order.html
- 한빛+: https://www.hanbit.co.kr/

## 이미지

공식 한빛아카데미 로고와 Pexels의 무료 사용 가능 이미지를 프로젝트 내부에 저장해 사용합니다. 상세 출처는 [IMAGE_CREDITS.md](./IMAGE_CREDITS.md)를 참고하세요.
